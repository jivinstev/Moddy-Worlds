## What's new in Scarcity Isle 0.1.7

- **Islands keep clear of arenas.** In a world that also has a Moddy Arena built with `/moddy arena create`, a new player's island is never placed where an arena stands, and an island already given out never moves.
- Built for Moddy core 1.0.12.

## What's new in Scarcity Isle 0.1.6

No gameplay changes since 0.1.5, only clearer pointers in the README. This release keeps the Isle's version in step with Moddy Arena 0.1.6, on the same Moddy core 1.0.9.
